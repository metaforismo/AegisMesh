# Support

AegisMesh is a community-supported open-source project.

- **Questions / usage:** GitHub Discussions (once the repo is public) or GitHub issues labeled `question`.
- **Bugs:** GitHub issues with the bug template; include `aegismesh doctor --json` output and the exact
  command that failed. Redact anything sensitive from event samples before attaching.
- **Security:** see SECURITY.md — never in public issues.
- **SLA:** none. Maintainers respond best-effort. If your deployment needs an SLA, you are free to contract
  support independently — AegisMesh has no commercial tier, and none is planned.

Please do not ask for features that violate the project's safety boundary (see AGENTS.md §Safety rules);
such requests will be declined with a pointer to the non-goals.
