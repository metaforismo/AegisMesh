Design system

One set of tokens and components for the operator console and this site. The files on this page are byte-identical copies of the console's tokens.css, base.css and components.css; a test fails if they drift. Follow your OS for light or dark.

  • Evidence is never interface. Attacker-controlled strings always wear the evidence treatment and are only ever text.
  • Never color alone. Severity is a five-step meter plus a word. Classification is a shape plus a word. State badges differ in shape too.
  • Calm and dense. Cool graphite neutrals, one cobalt accent, 13–14px body text, a 4px grid.
  • Honest numbers. Changes against the previous window are neutral ink. More observations are not styled as good or bad.
  • System fonts only. Nothing is fetched from another origin.

Identity

A written briefing inside an instrument. The console stays a calm graphite-and-cobalt instrument; page titles, the situation brief and the session sentence speak in the platform's serif (--font-display: New York, Iowan Old Style, Charter, Georgia), like a briefing a defender reads. Everything operational stays in the sans, numbers are tabular, and monospace uses a slashed zero.

The mesh appears as a faint lattice (--lattice-line, --lattice-node) on the sign-in page, in empty states and behind the landing hero. It is decorative and carries no information, so it never sits behind data: console screens are a flat canvas.

In the console, colour goes on data, status and the one primary action. A selection (the current screen, a time window, a tab) is the label in full ink with a 1px cobalt line exactly as wide as its word; controls are fully round and flat, panels flat with a quiet hairline and no shadow.

Brand

The mark is a net closed around a lure: a diamond perimeter (the protective mesh), four links reaching in from its sides, and a solid diamond at the centre that they do not touch (the decoy, held in the net). It is one colour, drawn on a 24-unit grid, and legible from 16px. The wordmark is set in the display serif. Files: site/assets/brand/ (mark and lockup; colour, dark and one-colour variants).

  • Minimum size. 16px for the mark, 96px wide for the lockup; below that, the word alone.
  • Colour. Cobalt on light, #8ea5ff on dark, white on cobalt. Never two colours inside the mark, never a gradient.
  • Don't. Rotate it, outline the lure, join the links to the lure, add a shield or a lock, put it inside a container shape, stretch it, or set the wordmark in the sans.

Mesh, tempo, density

The Overview's sensor mesh draws sensors from overview.by_sensor around the console core. Node area follows events; a ring marks a sensor with events in the newest bucket and a dashed node one without. Every node is a link with its name and count in text.

The session tempo ribbon puts every event on one axis: gaps on a log scale, quiet stretches over five minutes as labelled breaks, stage bands underneath, taller ticks for correlation signals. In the console it has one tab stop and arrow keys, and hovering a tick highlights the event in the list.

Row density is comfortable or compact, toggled in the console's top bar and remembered in this browser. Rows are told apart by rules and alignment, never zebra striping. Where an empty list is a normal state, the empty state draws a small lattice with one decoy and a probe line that stops short of it.

Evidence text

The signature element. Anything an attacker could have influenced (paths, previews, user agents, tool names, summaries, source keys) is set in monospace on a faint violet inset, inline or as a block. It is rendered as text only, so markup in it stays visible as characters.

Request: GET /<script>alert(1)</script> → 404 from 2001:db8::1f

tools/call read_file path="../../etc/passwd" prompts/get name="ignore previous instructions 🙂"

Do use it for every API string marked as evidence in the contract. Don't use it for interface text, ids or rule-authored reasons.

Severity

A five-segment meter: the number of filled segments is the rank, so it reads in grayscale and for every color-vision type. The word is always present. Events without a finding say so.

Tables

Sticky header, tabular numerals, right-aligned counts. Times are relative (“2 min ago”, “3 h ago”, “yesterday 14:03”, “3 days ago”, then the date) with the absolute UTC time in <time datetime>, the title, the peek and visually hidden text. A header is a sort button (.th-sort, aria-sort) only when every row is already in the browser; paged lists keep the server’s order. The mark is a filled triangle for the active direction, a faint one otherwise; in numeric columns it sits left of the label. A table wider than its column scrolls inside its wrapper. Below 720px a table becomes a list of labelled cards; labels come from interface text only.

Elevation

Three planes. Panels and tiles sit on the canvas, popovers and tooltips float over content, dialogs, drawers and the palette cover it. Light depth comes from soft shadows; dark depth comes from surface steps and a one-pixel inner highlight, because shadows vanish on dark canvases. Each theme has its own values.

Motion

Motion is for spatial continuity, state-change feedback and first impressions. Frequent keyboard actions stay instant. Only transform, opacity and short color feedback animate. Under reduced motion every duration token is zero: nothing moves, end states still apply.

  • Never animates: the command palette and shortcut sheet (opened by keyboard), j/k row movement, filters, table sorting and paging, numbers changing.
  • Animates briefly: route content (a 10px directional slide), dialogs and the side panel (interruptible transitions), toasts, the nav indicator, copy confirmation, chart entry and hover, live rows (a color wash, no movement).
  • Ambient: only the slow breathing of the mesh nodes on the sign-in page and the landing page, and the live dot ring. All stop under reduced motion.

Overlays & keys

The palette (⌘ K or Ctrl K) searches events on the server and jumps to screens, sources, rules, sensors, investigations and Guide entries, with recently opened items first; it also runs actions (including “Switch tenant: …” when the session has several tenants). Top-bar menus (tenant switcher, account) are native popovers that never animate; the current tenant is marked with a check and the word “Current”, never by color alone. Source keys keep the evidence treatment even here. Toasts stack newest-last, pause while hovered or hidden, and errors stay longer. Ids and hashes carry a copy button whose icon turns into a check.
